---> explaination 

docker run -d \
  --name my-postgres \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=admin123 \
  -e POSTGRES_DB=learnpg \
  -p 5432:5432 \
  postgres:17

1. docker run : Tells Docker to create and run a new container.
2. -d : Runs the container in detached mode (background).
3. --name my-postgres : Assigns a custom name my-postgres to the container.
4. -e POSTGRES_USER=postgres : Environment variable to create a superuser inside PostgreSQL named admin. By default, if not set → the user would be postgres.
5. -e POSTGRES_PASSWORD=**** : Sets the password for the POSTGRES_USER (postgres). Mandatory: PostgreSQL won’t start without a password.
6. -e POSTGRES_DB=postgres: Creates a database named postgres automatically at startup. By default, only a database named after the user is created.
7. -p 5432:5432 : Port mapping → host:container. Exposes PostgreSQL’s default port 5432 to your local machine. You can connect using localhost:5432.
8. postgres:17 (f49abb9855df) :Image name + tag. postgres → official PostgreSQL image. :17 → version (latest stable release).

---> Instal postgres on  local machin (VM)

-Steps to install postgresql-client-17 on Ubuntu (VirtualBox VM):
-Add PostgreSQL APT repository (for Ubuntu 24.04 “noble”)
Run this (it will create the repo file):

echo "deb http://apt.postgresql.org/pub/repos/apt noble-pgdg main" | \
sudo tee /etc/apt/sources.list.d/pgdg.list

-Add PostgreSQL GPG key (modern way)
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | \
sudo tee /etc/apt/trusted.gpg.d/postgresql.gpg > /dev/null

Update package list
sudo apt-get update
sudo apt-get install -y postgresql-client-17
